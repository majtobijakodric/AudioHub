# AudioHub

AudioHub is a backend for a music web app. It handles user accounts, searches YouTube for songs, and downloads audio files that the app can use.

## Tech Stack
- Node.js
- TypeScript
- Express
- Prisma
- MySQL / MariaDB
- `yt-search`
- `yt-dlp-wrap`
